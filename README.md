# Template Three: Kasper

A multi-section landing page called Kasper, with a background video, built to practice HTML and CSS.

**Live demo:** https://moh9180812-cyber.github.io/Html_And_Css_Template_Three/

## Features
- Long scrolling page with several sections
- Background video
- Font Awesome icons

## Built with
HTML, CSS, Font Awesome

## Run locally
```bash
git clone https://github.com/moh9180812-cyber/Html_And_Css_Template_Three.git
cd Html_And_Css_Template_Three
```
Open `index.html` in your browser. No build step or install needed.
